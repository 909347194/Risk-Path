## Q1: Label-Setting 是什么意思？

### 问题

> Label-Setting：同一空间位置保留多个非支配标签 (t, H, J)…… 这一部分是什么意思？

### 回答

**一句话解释**：同一个空间位置，可能有多条路径以不同的代价组合到达，Label-Setting 让它们共存，直到证明某条确实更差才淘汰。

**为什么需要它？**

假设从起点飞到位置 A，有两条路：

| | 路径1（高空绕行） | 路径2（低空穿楼） |
|---|---|---|
| 到达时间 t | 早 | 晚 |
| 累积危险 H | **高** | **低** |
| 累积代价 J | **低** | **高** |

哪条"更好"？**取决于你更在乎什么**。如果用普通 A*（只看 J），会丢掉路径1。但如果后续路径1能接上一段低风险区域，最终结果可能更好。

**三个维度的含义**：

- **t（到达时间）**：越早越好——时间越往后，人口密度/天气可能恶化
- **H（累积危险率）**：越低越好——$H = -\ln P_{surv}$，用对数把连乘变连加，数值稳定
- **J（累积代价）**：越低越好——融合了致命风险+财产+噪声+距离的加权和

**支配关系（核心规则）**：

> $L_{old}$ 支配 $L_{new}$ = $t_2 \leq t_1$ **且** $H_2 \leq H_1$ **且** $J_2 \leq J_1$（至少一项严格小于）
> 意思是：$L_{old}$ 在所有维度上都不差于 $L_{new}$，至少有一个更好 → $L_{new}$ 没有存在价值，剪掉。

**图示**：

```
H ↑
  │  ★ 被支配（t、H、J 都更差）→ 剪枝
  │
  │  ● 非支配标签 A（快但危险）
  │
  │     ● 非支配标签 B（慢但安全）
  │
  └──────────────→ t
        J 方向指向纸内

  ● = Pareto 前沿上的标签（互不支配，都保留）
  ★ = 被支配的标签（被剪掉）
```

**每位置最多 8 个标签**：防止搜索爆炸。如果某位置已有 8 个非支配标签，新标签想进来，必须淘汰 J 最大的那个，否则被拒绝。

**目标处的 Pareto 前沿**：

```
终点的标签集合：
  (t=50,  H=0.01, J=3.2)   ← 最终选这条（J最小）
  (t=45,  H=0.05, J=3.8)   ← 更快但更危险
  (t=60,  H=0.005, J=4.1)  ← 最安全但最慢
```

返回 J 最小的那条，但保留完整 Pareto 前沿供决策者参考。

**与普通 A* 的区别**：

| | 普通 A* | Label-Setting A* |
|---|---|---|
| 每个位置保留 | 1 个最优标签 | **多个**非支配标签 |
| 支配判据 | 仅 J | **(t, H, J) 三维** |
| 输出 | 1 条最短路径 | **Pareto 前沿** + 推荐路径 |
| 适用场景 | 单目标 | **多目标权衡** |

## Q2: 单目标加权 vs 多目标 Pareto 前沿是什么意思？

### 问题

> Pareto 支持：无（单目标加权） vs 多目标 Pareto 前沿；这个是什么意思？

### 回答

**Dong et al. 的做法：单目标加权**

把所有风险压成一个数字，然后找最小：

$$J = w_1 \cdot \text{路径长度} + w_2 \cdot \text{风险} + w_3 \cdot \text{风成本} + w_4 \cdot \text{噪声}$$

然后优化这个单一数值 J。

**问题**：$w_1, w_2, w_3, w_4$ 怎么定？

```
权重 (安全优先):  w = [0.1, 0.6, 0.1, 0.2] → 得到路径 A
权重 (效率优先):  w = [0.6, 0.1, 0.2, 0.1] → 得到路径 B
权重 (安静优先):  w = [0.2, 0.2, 0.1, 0.5] → 得到路径 C
```

你只知道这三条路径各自的 J 值，但不知道"安全换效率的最优交换比例是多少"。而且换一组权重就要重跑一次。

**我们的做法：Pareto 前沿**

同时保留多个互不支配的解，输出完整的权衡曲线：

```
噪声 ↑
  │
  │  ★ C (最安静，但更远更危险)
  │
  │    ★ A (均衡)
  │
  │      ★ B (最快，但更危险更吵)
  │
  └──────────────────→ 致命风险

  这条曲线 = Pareto 前沿
  线上的每个点都是"不被其他解全面超越"的解
```

**具体例子**：

| 路径 | 致命风险 | 噪声 | 时间 |
|------|---------|------|------|
| 路径A | 0.01 | 0.05 | 80s |
| 路径B | 0.03 | 0.01 | 75s |
| 路径C | 0.02 | 0.03 | 82s |

Pareto 前沿 = {A, B}（互不支配）：
- A vs B：A 更安全，B 更安静更快 → 都保留
- C 被 A 支配（A 在风险和时间上都 ≤ C）→ C 被淘汰

**对决策者的意义**：

```
单目标加权:  "给你一条路，自己看着办"
Pareto 前沿: "给你完整的权衡曲线，你自己选"

- 监管部门 → 选最安全的
- 物流公司 → 选最快的
- 社区居民 → 选最安静的
- 综合考虑 → 选拐点处的
```

**一句话**：Dong 给你一个数字，我们给你一条曲线。

## Q3: 4D A* 是真的在 4D 空间搜索吗？

### 问题

> 在四维时空网格（x, y, z, t）上搜索最优路径？？？是吗？

### 回答

**不是。搜索空间是 3D，时间是推导变量。**

```
搜索空间:  (x, y, z)    ← 纯 3D 空间搜索
时间维度:  非搜索维度    ← 由物理规律推导，不是独立变量
```

时间是确定性推导的，不是搜索出来的：

```python
dt = dist / uav_speed              # 飞行距离 / 速度 = 时间增量
new_abs_time = current_abs_time + dt  # 绝对时间单调递增
t2_idx = get_time_index(new_abs_time)  # 查4D风险张量
```

| | 表述 | 实际 |
|---|---|---|
| 搜索空间 | (x,y,z,t) 四维 | **(x,y,z) 三维** |
| 时间 | 独立搜索维度 | **物理推导，单调递增** |
| "4D" 含义 | 搜索空间4维 | **风险张量是4维**（用于查表） |

**真正的算法结构**：TD-RiskA*（Time-Dependent Risk A*）+ Label-Setting

1. **3D 空间 A***：26 邻接扩展，欧几里得启发式
2. **时间在线采样**：每步根据物理距离/速度推进绝对时间，从 4D 风险张量查当前时刻的风险值
3. **Label-Setting 支配剪枝**：同一空间位置保留多个非支配标签 (t, H, J)
4. **多目标 Pareto 前沿**：目标处所有非支配标签中取 J 最小

**为什么叫 "4D"**：指的是 EnvTensor 的 4D 张量（nx, ny, nz, nt），不是搜索空间。更准确的名字是 **Time-Dependent 3D Risk-A* with Label-Setting（TD-RiskA*）**。

## Q4: 搜索空间会不会爆炸？

### 问题

> 1、回答我们的搜索空间会不会爆炸？

### 回答

**不会。** 四层防线保证确定性有界：

| | 理论上限 | 实际估算 |
|---|---|---|
| 空间 cells | 60×60×12 = **43,200** | ~2,160（高度约束+A*探索） |
| 标签总数 | 43,200×8 = **345,600** | ~6,480（每位置1-3个） |
| 邻居扩展 | **899万** | ~17万 |
| 内存 | ~66 MB | **~1.2 MB** |

**四层防线**：

```
第 1 层: 搜索空间是 3D 不是 4D
         时间是推导变量（dt=dist/speed），不独立搜索
         → 从 415万 states 降到 4.3万

第 2 层: max_labels_per_cell = 8（硬上限）
         → 确定性有界，不可能无限增长

第 3 层: 三维支配剪枝 (t, H, J)
         → 实际每位置只保留 1-3 个标签（远低于 8）

第 4 层: A* 启发式 + 硬约束剪枝
         → 只探索 5-15% 的空间
         → survival_threshold / battery / 爬升率剪掉不可行路径
```

唯一可能变慢的场景：`complete_pareto=True` + 无硬约束 + 大网格。此时 ~900 万扩展，Python 单机约几分钟，仍不爆炸。

## Q5: 用"空域饱和度"做多机协调可行吗？

### 问题

> 我们如果维护一个栅格动态的无人机占有数量，"空间饱和度"，是不是也能在一定程度上进行时空协调？

### 回答

**可行，而且比直接上 CBS 更聪明。**

核心思路：用"空域拥挤度"作为动态风险信号来近似多机协调，不需要进入多机联合搜索。

```
现有: Cost_total(x,y,z,t) = f(crash, fatal, noise, property, obstacle)
新增: Cost_crowd(x,y,z,t) = f(occupancy(x,y,z,t))
                           ↑
                    4D 时空占用计数张量
```

每架 UAV 规划时查询当前空域拥挤度，高拥挤区域自动产生代价惩罚 → 路径自然分散。

**与经典多机方法的定位**：

| 方法 | 协调能力 | 计算量 | 完备性 |
|------|---------|--------|--------|
| CBS (Conflict-Based Search) | **精确无碰撞** | 指数级 | 完备 |
| 优先级规划 | 近似 | 线性 | 不完备 |
| **空域饱和度（我们的）** | **软协调** | **单机规划 × N** | 不完备 |
| 4D 联合搜索 (Dong) | 精确 | 状态空间爆炸 | 完备 |

**实现方案**：

```
1. 顺序规划（简单版）:
   for each UAV_i:
     路径_i = TD-RiskA*(Cost_total + λ·Cost_crowd)
     occupancy += PathContribution(路径_i)  # 回写占用

2. 并行协调（进阶版）:
   同时规划 → 迭代更新 occupancy → 收敛判定

3. 时间窗预留（更强版）:
   occupancy(x,y,z,t) 记录占用 → 高占用自动惩罚
   → UAV 自动错开时间/空间
```

**优势**：

1. 零架构改动：只是 EnvTensor 加一个分量
2. 计算量可控：N 架 UAV = N 次单机规划
3. 天然 4D 语义：occupancy(x,y,z,t) 就是时空协调信号
4. 与 Dong 的差异：他们用联合搜索精确协调，我们用拥挤度软协调——更适合大规模
5. 可扩展到走廊：occupancy 高的区域自动形成"空中走廊"

**局限**：

1. 不保证无碰撞 → 缓解：加安全间隔约束（时间缓冲）
2. 顺序规划有偏 → 缓解：随机顺序 / 迭代优化
3. 栅格粒度权衡 → 太粗漏检，太细计算量大

**对论文的价值**：

这比直接上 CBS 更聪明：
- CBS 解决的是"精确无碰撞"（工程问题）
- 空域饱和度解决的是"如何用时空异质性框架自然地实现多机协调"（**科学问题**）

而且它和核心命题完美一致——**时空异质性不仅影响风险，也影响空域容量**。

## Q6: A0 和 A1c 是什么关系？

### 问题

> A0 和 A1c 是什么关系？原 DMDE 是耦合的呀

### 回答

原 DMDE 确实是耦合的。A0 和 A1c 的关系是：

**共用同一套耦合公式**（F = f(CR), GMR = g(CR, δ)），**区别只在 CR 的来源**：

```
A0 (Vanilla DMDE):
  CR ← 公式 3-9 动态调度（1→0 单调衰减）
  F  ← 公式 3-11 (CR)
  GMR ← 公式 3-12 (CR, δ)

A1c (Coupled + LLM):
  CR ← LLM 选择
  F  ← 公式 3-11 (CR)     ← 和 A0 一样
  GMR ← 公式 3-12 (CR, δ)  ← 和 A0 一样
```

**A1c 就是"把 A0 的 CR 来源从公式换成 LLM"，耦合结构完全保留。**

四个实验的逻辑链条：

| 对比 | 变量 | 隔离的效应 |
|------|------|-----------|
| A0 vs A1c | CR 来源（公式→LLM） | LLM 决策的价值 |
| A1c vs A1 | 耦合→解耦 | 解耦的价值 |
| A1 vs A1n | 有无 CR 通道 | CR 通道的残余效应 |
| A0 vs A1 | 全部差异 | 整体方法效果 |

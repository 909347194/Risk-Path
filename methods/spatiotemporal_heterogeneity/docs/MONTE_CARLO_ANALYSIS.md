# 蒙特卡洛方法适用性分析

> 更新时间：2026-07-24
> 关联实验：EXP1 微观机制验证

---

## 1. 蒙特卡洛方法简介

蒙特卡洛是一种基于大量随机抽样的数值计算方法。核心思路：当问题中存在大量不确定、随机变化的参数时，计算机自动重复上万次随机试验，模拟海量真实可能发生的场景，再统计所有试验结果，算出概率、风险均值、极端事故发生可能性。

---

## 2. 当前模型的确定性假设

本文 TD-RiskA\* 算法基于**确定性风险张量**进行路径规划：

| 输入参数 | 当前处理 | 确定性假设 |
|---|---|---|
| 风速场 $v_{wind}(x,y,z,t)$ | 固定值（如 12-18 时中心 8 m/s） | 风速预报完全准确 |
| 降雨场 $I_{rain}(x,y,t)$ | 固定值（如 14-20 时中心 15 mm/h） | 雨强预报完全准确 |
| 人口密度 $\rho_{pop}(x,y,t)$ | POI 潮汐模型确定性生成 | 人流服从固定时间规律 |
| 坠机概率 $P_{crash}$ | $\lambda_{base}$ 经验常数 | 基准失效率恒定 |
| 建筑高度 $h_b(x,y)$ | 固定值 | 测量无误差 |

算法输出：**单条最优路径** + **单组风险指标**（存活率、累积致死、累积噪声）。

---

## 3. 现实中的不确定性来源

| 参数 | 不确定性来源 | 典型波动范围 | 概率分布特征 |
|---|---|---|---|
| 风速 | 湍流、局地效应、预报误差 | ±3~5 m/s | 正态/Weibull |
| 降雨 | 阵雨、间歇、空间不均匀 | 0~2× 预报值 | 对数正态/伽马 |
| 人口密度 | 突发事件、天气影响、节假日 | ±30~50% | 泊松/负二项 |
| 坠机概率 | 硬件随机故障、鸟击、GPS 丢失 | λ 波动 ±50% | 指数/威布尔 |
| 建筑高度 | 测量误差、临时建筑 | ±1~2 m | 均匀/正态 |

## 4. 蒙特卡洛路径风险评估框架

### 4.1 算法流程

```
输入：基准风险参数 θ₀ = {v_wind, I_rain, ρ_pop, λ_base, h_b}
      随机扰动分布 D = {D_wind, D_rain, D_pop, D_lambda, D_building}
      采样次数 N

for i = 1 to N:
    # 1. 从扰动分布中采样
    v_wind' = v_wind + ε_wind,  ε_wind ~ D_wind
    I_rain' = I_rain + ε_rain,  ε_rain ~ D_rain
    ρ_pop'  = ρ_pop × (1 + ε_pop), ε_pop ~ D_pop
    λ'      = λ_base × (1 + ε_λ),  ε_λ ~ D_lambda

    # 2. 构建随机风险张量
    Cost'_total(x,y,z,t) = f(P_crash', E_fatality', R_noise')

    # 3. 路径规划
    path_i = TD-RiskA*(Cost'_total)

    # 4. 记录结果
    记录：路径_i, 存活率_i, 累积致死_i, 累积噪声_i, 运行时间_i

# 5. 统计分析
输出：
    路径长度:  均值 ± 标准差
    存活率:    均值 ± 标准差, 95% CI, 5th percentile (最差情况)
    累积致死:  均值 ± 标准差, 95th percentile (最坏情况)
    路径变化:  频率 (多少次产生不同路径)
    计算时间:  均值 ± 标准差
```

### 4.2 不确定性传播模型

**风速扰动**（基于大气湍流理论）：
$$v'_{wind}(x,y,z,t) = v_{wind}(x,y,z,t) + \mathcal{N}(0, \sigma_{wind}^2)$$
其中 $\sigma_{wind}$ 取风速预报值的 20%（气象学标准）。

**降雨扰动**（基于降水空间变异性）：
$$I'_{rain}(x,y,t) = I_{rain}(x,y,t) \times \text{LogNormal}(0, \sigma_{rain}^2)$$
其中 $\sigma_{rain} = 0.3$（降水空间变异系数）。

**人口密度扰动**（基于泊松过程）：
$$\rho'_{pop}(x,y,t) = \rho_{pop}(x,y,t) \times (1 + \text{Poisson}(\lambda_{pop}) / \lambda_{pop} - 1)$$
简化为 $\rho'_{pop} = \rho_{pop} \times (1 + \epsilon)$, $\epsilon \sim \mathcal{N}(0, 0.2^2)$。

**坠机概率扰动**（基于硬件可靠性）：
$$\lambda'_{base} = \lambda_{base} \times (1 + \epsilon_\lambda), \quad \epsilon_\lambda \sim \mathcal{N}(0, 0.5^2)$$

## 5. 对论文贡献的提升分析

### 5.1 当前论文的薄弱点

| 薄弱点 | 具体表现 | 蒙特卡洛如何弥补 |
|---|---|---|
| 安全论证不足 | "存活率 0.19"——单次确定性结果 | "存活率 0.19±0.03，最差 0.12"——统计保障 |
| 路径鲁棒性未知 | 不确定参数变化时路径是否仍然安全 | 路径变化频率 + 风险波动范围 |
| 与文献差距 | Clovis 等人用 MC 评估 TPR，本文不用 | 对齐领域标准方法 |
| §6 实验待写 | 需要更多实验内容 | MC 可作为独立实验小节 |

### 5.2 论文叙事中的定位

蒙特卡洛在论文中的定位不是核心算法创新，而是**鲁棒性验证工具**：

```
论文主线：
  风险建模（§4） → 路径规划算法（§5） → 确定性实验（§6.1~6.4） → 鲁棒性验证（§6.5）

§6.5 蒙特卡洛鲁棒性分析：
  "为验证 TD-RiskA* 在参数不确定性下的鲁棒性，本节对关键风险参数
   施加随机扰动，执行 N 次蒙特卡洛模拟，统计路径风险的波动范围。"
```

## 6. 实施方案

### 6.1 分层实施策略

| 层次 | 场景 | MC 次数 | 单次耗时 | 总耗时 | 可行性 |
|---|---|---|---|---|---|
| 微观 (Exp1~3) | 40×40×12×24 | 1000 | ~10ms | ~10s | ✅ 可接受 |
| 宏观 (Exp4) | 100×100×12×48 | 100 | ~13s | ~20min | ✅ 可接受 |
| 大规模 | 200×200×12×96 | 50 | ~2min | ~1.5h | ⚠️ 勉强 |

### 6.2 扰动参数设计

| 参数 | 扰动类型 | σ / 范围 | 文献依据 |
|---|---|---|---|
| 风速 | 高斯加性 | σ = 0.2 × v_wind | WMO 气象预报不确定性标准 |
| 降雨 | 对数正态乘性 | σ = 0.3 | 降水空间变异性（Ciach et al., 2007） |
| 人口密度 | 高斯乘性 | σ = 0.2 | 城市人口流动统计特征 |
| 坠机率 λ | 高斯乘性 | σ = 0.5 | 无人机可靠性文献（Dalamagkidis et al.） |

### 6.3 预期输出指标

| 指标 | 含义 | 论文价值 |
|---|---|---|
| 存活率 95% CI | [μ-1.96σ, μ+1.96σ] | 安全保障置信度 |
| 存活率 5th percentile | 最差 5% 场景下的存活率 | 极端情况安全底线 |
| 路径变化频率 | N 次中产生不同路径的比例 | 路径鲁棒性 |
| 风险波动系数 | σ/μ (变异系数) | 风险可控性 |
| 累积致死 95th percentile | 最坏 5% 场景的致死风险 | 最差情况后果 |

### 6.4 预期结果假设

基于当前实验的确定性结果，蒙特卡洛可能呈现以下规律：

1. **Calm 场景**：风/雨扰动小 → 风险波动小 → 路径稳定
2. **Wind 场景**：风速扰动大（σ=0.2×15=3m/s）→ P_crash 波动大 → 路径可能变化
3. **夜间场景**：人口扰动 → 噪声波动 → 路径可能变化
4. **风暴窗口 (Exp4)**：风速在 V_limit 附近 → 小扰动可能导致 P_crash 从 0.5 跳到 1.0 → 路径高度敏感

## 8. 结论与建议

### 是否需要蒙特卡洛？

**需要，但定位为鲁棒性验证工具，而非核心算法。**

| 理由 | 权重 |
|---|---|
| 风险本身就是概率性的，路径规划应考虑不确定性 | ⭐⭐⭐ |
| 安全论证需要统计保障（置信区间 > 单点值） | ⭐⭐⭐ |
| 与领域标准方法对齐（Clovis 等人用 MC） | ⭐⭐ |
| §6 实验需要更多内容 | ⭐⭐ |
| 计算量可控（微观 10s，宏观 20min） | ✅ |

|---|---|---|

| P3 | 论文 §6.5 撰写蒙特卡洛鲁棒性分析 | 2~3h |

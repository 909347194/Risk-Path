# EXP1: 微观机制验证实验 (Micro-Scale Mechanism Validation)

## 1. 实验目标

在 400m × 400m 的合成城市场景中，验证 TD-RiskA\* 算法的四个核心学术观点：

1. **时间节律自适应性** — 同一 OD 对在不同出发时刻生成不同路径
2. **微气象-地形耦合避让** — 风/雨热点与建筑峡谷耦合时路径主动绕行
3. **噪声-安全帕累托权衡** — 调整权重时噪声与安全呈现 Pareto 前沿
4. **多标签剪枝计算优越性** — Label-Setting 剪枝比无剪枝更快且不损失最优性

## 5. 实验结果

### 实验 1: 时间节律自适应性

| 出发时刻           | 路径长度 | 存活概率  | 累积噪声   | 搜索节点 | 运行时间  |
| ------------------ | -------- | --------- | ---------- | -------- | --------- |
| 08:00 (早高峰)     | 495m     | 0.187     | 0.0025     | 179      | 7ms       |
| 12:00 (午间)       | 495m     | 0.058     | 0.0021     | 179      | 8ms       |
| **18:00 (晚高峰)** | **513m** | **0.011** | 0.0016     | **4864** | **638ms** |
| 22:00 (夜间)       | 495m     | 0.259     | **0.0040** | 179      | 7ms       |

**结论**：

- 18:00 晚高峰路径明显更长（+18m），因中心区域风+雨导致 P_crash 高达 0.38
- 22:00 夜间噪声成本最高（T_penalty ×10），存活概率最高（无风雨）
- 12:00 午间存活概率最低（风热点活跃），但路径未变（风险区在对角线之外）

### 实验 2: 微气象-地形耦合避让

| 条件     | 算法          | 路径长度 | 存活概率  | 累积伤亡    | 运行时间 |
| -------- | ------------- | -------- | --------- | ----------- | -------- |
| Calm     | Distance-only | 495m     | 0.270     | 0.00096     | 7ms      |
| Calm     | TD-RiskA\*    | 495m     | 0.270     | 0.00096     | 7ms      |
| **Wind** | Distance-only | **559m** | 0.013     | 0.00226     | 866ms    |
| **Wind** | TD-RiskA\*    | **577m** | **0.014** | **0.00089** | 2242ms   |
| Rain     | Distance-only | 495m     | 0.106     | 0.00103     | 7ms      |
| Rain     | TD-RiskA\*    | 495m     | 0.106     | 0.00103     | 7ms      |

**结论**：

- **Wind Canyon**: TD-RiskA\* 绕行更远（577m vs 559m），累积伤亡降低 61%（0.00089 vs 0.00226）
- Calm/Rain: 两种算法路径相同，因风险未超过阈值
- 风场是最显著的风险因子（f_wind 在 V_limit 附近指数增长）

### 实验 3: 噪声-安全帕累托权衡

| 权重配置 | w_noise | 路径长度 | 存活概率 | 噪声   | 目标函数 |
| -------- | ------- | -------- | -------- | ------ | -------- |
| w_n=0.05 | 0.05    | 495m     | 0.269    | 0.0041 | 18.58    |
| w_n=0.15 | 0.15    | 495m     | 0.269    | 0.0041 | 15.73    |
| w_n=0.30 | 0.30    | 495m     | 0.269    | 0.0041 | 11.44    |
| w_n=0.50 | 0.50    | 495m     | 0.269    | 0.0041 | 5.72     |

**结论**：

- 当前场景下权重扫描未改变路径（噪声贡献 ~0.004 vs 距离贡献 ~28）
- 归一化后的目标函数 J 随 w_noise 增大而减小（符合预期）
- 需更强的噪声对比（如穿过住宅区 vs 绕行）才能显现 Pareto 前沿

### 实验 4: 多标签剪枝效率

| 策略              | max_labels | 路径长度 | 目标函数 | 运行时间 | 搜索节点 |
| ----------------- | ---------- | -------- | -------- | -------- | -------- |
| No Pruning (k=50) | 50         | 495m     | 11.44    | 8.0ms    | 179      |
| Strict (k=1)      | 1          | 495m     | 11.44    | 7.6ms    | 179      |
| Proposed (k=4)    | 4          | 495m     | 11.44    | 7.1ms    | 179      |
| Proposed (k=8)    | 8          | 495m     | 11.44    | 7.1ms    | 179      |
| Proposed (k=16)   | 16         | 495m     | 11.44    | 6.5ms    | 179      |

**结论**：

- 所有策略均找到相同最优路径（495m），验证了剪枝不损失最优性
- 运行时间差异不大（6.5-8.0ms），因搜索空间较小（40×40 网格）
- Strict (k=1) 即单标签也能找到最优解，说明该 OD 对路径上标签冲突少

## 8. 已知限制

1. **网格较小** (40×40)：搜索空间有限，剪枝效果不显著
2. **OD 对单一**：仅使用对角线 OD，未覆盖多种路径场景
3. **合成数据简化**：建筑、土地利用为规则分布，非真实城市形态
4. **无 EDA 对比**：当前仅实现 A\*，未包含 EDA-K-means 层次化算法

# Exp 1 — 时空异质性表征 (Spatiotemporal Heterogeneity Characterization)

> 实验类型：机制验证（论文证据链第 1 环：_风险场是否明显随空间和时间变化？_）
> 入口：`python3 run.py`（约 4–5 min，含权重敏感性扫描；关闭敏感性时约 1.5 min）
> 产物：`results/fig1_risk_field.png`、`fig2_drivers.png`、`fig3_path_comparison.png`、
> `fig4_weight_sensitivity.png`、`metrics.csv`、`path_difference.csv`、
> `heterogeneity.csv`、`sensitivity.csv`

## 1. 目的 (Purpose)

回答论文的第一个、也是最基础的证据链问题：

> **低空城市风险是否同时随「空间」和「时间」显著变化？**

如果风险场是静态的（如一张时间平均地图），那么"显式建模时空异质性"就失去意义；
只有当风险场确实随 x/y/z/t 变化，且这种变化能改变最优路径，后续 Exp 2（Static vs
Spatiotemporal）的对比才有立足点。

## 2. 数据与方法 (Data & Method)

**数据源：真实数据**（`data/02_processed` 顶层已准备好的数组，**只读加载**），
宏观网格 **100×100×12**（dx=48.459 m, dy=47.936 m），96 时相 × 15 min。

> ⚠ 刻意绕过 `DataPipeline(data_type='real').run_all()`：该管线会从 `01_raw`
> 重算并**覆盖**已提交数据（实测重算结果与提交版本相对差 50%–90%，POI/人口
> 全部不同）。本实验用 `np.load` 逐文件只读加载并做形状校验，保证用的就是
> 「准备好的」数据。

1. `build_risk_tensors` 组装四维风险张量 `Cost(x,y,z,t)`，风场由情景化模型生成
   （`wind_environment.mode=scenario`，moderate；时间变化 `V_ref(t)`、高度修正
   `F_z(z)`、城市形态遮蔽 `F_urban(x,y)`）；**降雨暂不考虑**（无真实降雨数据）；
2. **60 m 定高巡航**：`cruise_altitude_lock=true` 把搜索限制在 z=5 层（配送无人机
   定高巡航），路径正好落在 Figure 1 的风险切片上，单次搜索 ~4.5 s；
3. **OD = (3,93) → (85,10)**：起点固定为 WGS84 (23.113833°N, 113.292737°E)，
   换算格索引 (3,93)（格心 113.292749°E / 23.114034°N，研究区西—北侧滨水起点）；
   终点沿用人口核心 B 附近 (85,10)，构成横贯研究区的需求走廊；
4. 在 **08:00 / 12:00 / 18:00 / 22:00** 各跑一次 `TD-RiskA*`（在线采样
   `risk_at(x,y,z,t)`）；
5. 输出 Figure 1–4 与四份 CSV（每时刻指标 / 路径两两偏差 / 异质性统计 / 权重敏感性）。

配置：`config.yaml` 只放实验专属参数（数据源、OD、出发时刻、权重、定高开关、
敏感性扫描），公共参数通过 `extends: ../../configs/common.yaml` 继承。

## 3. 结果 (Results, 2026-09-28)

> ⚠ 数值来源：本次运行产物 `results/metrics.csv`、`path_difference.csv`、
> `heterogeneity.csv`、`sensitivity.csv`。
> **本实验此前记录的「极差 1529 m、路线同伦类切换」是旧起点下的结果**；
> `c1fbb9b` 将 OD 起点改为网格 (3,93) 后该现象消失，结论已随之改变。

| 出发时刻 | 路径长度 (m) | P_surv | 备注          |
| -------- | ------------ | ------ | ------------- |
| 08:00    | 6389.868     | 0.0259 |               |
| 12:00    | 6339.286     | 0.0490 | 与 18:00 等长 |
| 18:00    | 6339.286     | 0.0710 |               |
| 22:00    | 6418.100     | 0.0641 |               |

- **路径长度极差 78.8 m（1.24%）**，两两最大平均几何偏离 **26.66 m**
  （小于一个格对角线 ≈ 68 m）→ 四个出发时刻**走的是同一条走廊**，
  未出现此前宣称的「路线同伦类切换」；
- 风险场本身**空间异质**：P_crash 空间 CV 0.4113 / 0.4369 / 0.4654 / 0.4486
  （08/12/18/22 时）；**时间异质**：格点级时间 CV 中位数 0.1405、时间相对极差
  中位数 0.3779；
- 驱动机制仍然存在（人口潮汐 + 风场昼夜节律，Figure 2），但在当前 OD 下
  **未能转化为路径差异**。

**结论（当前 OD + 主权重）：风险场确实时空异质（空间 CV ≈ 0.45、时间相对极差
≈ 0.38），但在 OD (3,93)→(85,10)、w_fatal/w_ops = 1000 下，TD-RiskA\* 对出发时刻的
响应很弱（极差 1.24%，四条路径几乎重合）。因此「出发时刻改变 → 最优路径改变」
在当前配置下尚未得到支持，证据链第 1 环需重选 OD 重建后方可引用。**

## 4. 权重标定与敏感性 (Weight Calibration & Sensitivity)

归一化单步成本中距离增量 `d/d_max ≈ 1`，而风险增量 `p_crash·(C/Ω) ≈ O(10⁻³)`，
故需 `w_risk / w_ops ≈ 10²–10³` 才能让风险参与选路。主设定取 **比值 1000**
（w_ops=0.03, w_fatal=30, w_prop=12, w_noise=7.5）。

**该比值位于阈值附近，必须连同敏感性一起解读（Figure 4 / sensitivity.csv）。**
扫描沿 w_fatal 变化（w_prop = 0.4·w_fatal、w_noise = 0.25·w_fatal 联动），实测：

| w_fatal/w_ops | 800   | **1000** | 1200  | 1400  |
| ------------- | ----- | -------- | ----- | ----- |
| 极差 (m)      | 107.0 | **78.8** | 28.2  | 0.0   |
| 极差 (%)      | 1.70  | **1.24** | 0.44  | 0.00  |

- 极差随风险规避程度**单调递减**，未出现「中间 regime 极差最大」的过渡带峰值；
- 各比值下极差均 ≤ 107 m（≤ 1.70%），即**路径对出发时刻的响应整体很弱**；
- 说明当前 OD 缺少真正可选的替代走廊（起点 (3,93) 位于研究区西北角），
  提高风险规避只能在同一走廊内微调，无法切换到另一条路。

> 注：此前记录的「0 / 1529 / 69 / 40」与「全直飞 → 混合 → 全绕行」三 regime 叙事
> 属于旧起点下的结果，已由本节实测数值取代。Exp 2 的对比仍固定在主设定上进行。

## 5. 备注 (Notes)

- 本实验定位为**机制/表征**，不做算法对比（Exp 2）与消融（Exp 3）；
- `P_surv` 数值偏低（本次 2.6%–7.1%）源于风险模型口径：`P_crash` 按 **15 min/格** 暴露
  计算，而 UAV 穿越一格仅约 7 s，累计危险率被显著放大。该口径影响所有实验的
  绝对存活率（不影响"路径随时刻变化"的相对判断），建议后续在模型层统一修正
  （按格穿越时间计 P_crash）并重新标定权重；
- 数据均为真实数据；建筑高度 0–225 m；人口峰值位置全天分布：
  (22,52) 51 时相、(72,18) 39 时相；
- **待办（重建证据链第 1 环）**：当前 OD (3,93)→(85,10) 下路径对出发时刻几乎不响应。
  建议重选 OD（穿越人口双核心、南北均有可行走廊），并评估解除 60 m 定高锁定
  （`cruise_altitude_lock: false`），重跑后再更新本节结论；
- `run.py` 中 `planner_cfg` 的权重兜底默认值（w_fatal=6.0 / w_prop=2.4 / w_noise=1.5）
  与 `config.yaml`（30 / 12 / 7.5）不一致，若 config 中缺失这些键会静默落到
  比值 200 的另一 regime，建议改为显式报错或与 config 对齐。

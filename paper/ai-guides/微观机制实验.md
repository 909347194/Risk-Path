微观机制实验的定位应该是：**用一个可控的小城市场景证明你的风险模型和路径规划机制确实会改变航路选择**，不是证明真实城市部署效果。

**1. 需要哪些数据，如何模拟**

微观实验不必一开始用真实 OSM/WorldPop/ERA5。建议用合成数据，保证每个风险因素可控、可解释。

需要的数据分 6 类：


| 数据                              | 用途                       | 微观模拟方式                                         |
| --------------------------------- | -------------------------- | ---------------------------------------------------- |
| 建筑高度**building\_height[x,y]** | 障碍物、城市峡谷、财产风险 | 放置若干矩形建筑，高度 20-80m，中间形成高楼峡谷      |
| 土地利用**landuse[x,y]**          | 噪声敏感度                 | 人工划分住宅区、学校/医院、商业区、工业区、绿地/水域 |
| POI 点                            | 人口潮汐                   | 放置 residential、office、transit、school 等点       |
| 基础人口/车辆密度                 | 伤亡风险、噪声暴露         | 用高斯热区模拟人口密集区，道路附近模拟车辆密度       |
| 风、雨场                          | 动态坠机概率               | 在城市峡谷或中央区域放一个高风速/强降雨热点          |
| 起点终点 OD                       | 路径规划                   | 固定西南到东北，保证直线路径穿过高风险区             |

建议构造三个竞争通道：

1. **中间短通道**：距离短，但穿过建筑峡谷、高风、高人口区。
2. **侧边安全通道**：距离稍长，但人口少、建筑少、风险低。
3. **高空通道**：可能降低噪声和障碍风险，但增加爬升/运营成本。

这样实验结果才会有可解释性：最短路会倾向走中间，风险感知路径会绕开热点

**2. 当前空间建模与划分是否合理**

你当前 **micro\_validation** 配置是：

区域大小：400m x 400m x 120m
水平格网：10m x 10m
垂直格网：10m
网格维度：40 x 40 x 12
时间步：24 个小时切片

这个设置用于微观机制实验是合理的。

优点：

* **40 x 40 x 12 = 19,200** 个空间体素，计算量可控。
* 10m 水平分辨率足够表达街区级建筑、道路和风险热点。
* 10m 高度层适合低空无人机场景，能表达 20m、40m、60m、80m 等建筑遮挡。
* 400m 尺度适合展示“短路径 vs 低风险绕行”的机制。

但有一个重要注意点：**时间分辨率不能按真实飞行过程理解**。

无人机速度如果是 10m/s，穿越 400m 只需几十秒到一两分钟。你现在的 1 小时时间片更适合表示“不同出发时刻的风险场”，例如 08:00、12:00、18:00、22:00，而不是路径飞行过程中每小时变化。

所以建议：

* 微观机制实验中，把 **t** 理解为“出发时刻对应的风险切片”。
* 先比较不同出发时刻的路径差异。
* 暂时不必强调飞行过程中风险连续变化。
* 后续宏观实验再用 15 分钟时间片，更适合真正的 4D 时间推进。

障碍物建模建议：

不可飞体素：z <= building_height(x,y) + safety_margin

不要把建筑只设成高成本，应该作为硬约束剪枝。

**3. 这个实验要说明什么**

微观机制实验至少要说明 4 件事。

第一，说明动态风险张量是有效的。

也就是：

* 风大、雨大、建筑密集处 **P\_crash** 更高。
* 人口/车辆密集处伤亡风险更高。
* 夜间住宅区噪声成本更高。
* 白天学校/医院噪声成本更高。

第二，说明路径规划真的在使用这些风险。

对比几条路径：


| 方法                    | 预期表现                                           |
| ----------------------- | -------------------------------------------------- |
| Shortest-A\*            | 路径最短，但可能穿过高风险区                       |
| StaticRisk-A\*          | 能避开平均高风险区，但不随时间变化                 |
| FullRisk-A\*            | 会根据风雨、人口、噪声和权重改变路径               |
| EDA + K-means + CostA\* | 在较小搜索空间中得到接近 FullRisk-A\* 的低风险路径 |

第三，说明“时间”会改变路径。

同一个 OD，建议测试：

`<span><span>08:00 早高峰</span> <span>12:00 白天</span> <span>18:00 晚高峰</span> <span>22:00 夜间</span></span>`

预期：

* 08:00 / 18:00 避开道路和交通节点。
* 12:00 避开学校/医院。
* 22:00 避开住宅区。

第四，说明“权重”会改变路径。

使用：

default
emergency
quiet_night
strict_safety

预期：

* **emergency** 更短、更直。
* **quiet\_night** 绕开住宅区。
* **strict\_safety** 绕开高人口、高建筑、高坠机概率区域。

最小可行实验建议先做这个：

一个 400m x 400m 合成街区
一个 OD
三个方法：Shortest-A* / StaticRisk-A* / FullRisk-A*
四个出发时刻：08:00 / 12:00 / 18:00 / 22:00
四个指标：路径长度、期望风险、噪声成本、总成本
一张路径叠加图 + 一张分项成本表`

这组实验跑通后，论文实验章节就有主心骨了。

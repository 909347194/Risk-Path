## 实验1：时间节律自适应性



**要证明的论点**：



> TD-RiskA* 能够感知城市时间节律，在不同出发时刻生成不同的最优路径。



**审稿人潜台词**：



*"你说时间很重要，但路径规划真的会因为出发时间不同而改变吗？如果不管几点出发路径都一样，你的'时间依赖'就是伪命题。"*



**实验逻辑**：



text

```
自变量：出发时刻 t ∈ {08:00, 12:00, 18:00, 22:00}
因变量：路径形状、存活概率、累积噪声
控制变量：同一 OD 对、同一网格、同一权重

如果路径在 18:00（晚高峰）与其他时刻不同 → 时间维度有实质影响
如果 22:00（夜间）噪声成本最高 → S-T 矩阵的昼夜惩罚生效
自变量：出发时刻 t ∈ {08:00, 12:00, 18:00, 22:00}
因变量：路径形状、存活概率、累积噪声
控制变量：同一 OD 对、同一网格、同一权重

如果路径在 18:00（晚高峰）与其他时刻不同 → 时间维度有实质影响
如果 22:00（夜间）噪声成本最高 → S-T 矩阵的昼夜惩罚生效
```



**当前结果已能支撑的结论**：



| 证据                           | 证明了什么                                     |
| ------------------------------ | ---------------------------------------------- |
| 18:00 路径更长（513m vs 495m） | 晚高峰风+雨导致中心区 P_crash 高，算法主动绕行 |
| 22:00 噪声成本最高（0.0040）   | 住宅区夜间 T_penalty ×10 生效                  |
| 12:00 存活率最低（0.058）      | 午间风热点活跃，P_crash 最高                   |
| 搜索节点 179→4864              | 晚高峰路径选择空间增大，算法需探索更多候选     |



**需要补充的证据**：



- 沿路径的 P_crash 时序采样图——展示算法在高风险区域"绕行"的具体位置
- 四条路径叠加在同一张城市地图上——视觉冲击力



**一句话结论**：



> 实验1 证明了"时间异质性不是噪声，而是影响路径形状的实质性因素"。

## 实验2：微气象-地形耦合避让



**要证明的论点**：



> TD-RiskA* 能够感知微气象与城市建筑的耦合效应，在高风险区域主动绕行，显著降低累积伤亡。



**审稿人潜台词**：



*"你搞了风场、降雨、城市峡谷三个因子的乘法耦合，这比简单模型复杂很多。这种复杂性真的带来更好的路径吗？还是只是增加了计算量？"*



**实验逻辑**：



text

```
自变量：环境条件（Calm / Wind / Rain）
对比算法：Distance-only vs TD-RiskA*
因变量：路径形状、累积伤亡、运行时间

如果 Wind 场景下 TD-RiskA* 累积伤亡显著低于 Distance-only → 风险感知有效
如果 Calm/Rain 场景下两者路径相同 → 算法不会过度反应
自变量：环境条件（Calm / Wind / Rain）
对比算法：Distance-only vs TD-RiskA*
因变量：路径形状、累积伤亡、运行时间

如果 Wind 场景下 TD-RiskA* 累积伤亡显著低于 Distance-only → 风险感知有效
如果 Calm/Rain 场景下两者路径相同 → 算法不会过度反应
```



**当前结果已能支撑的结论**：



| 证据                                                         | 证明了什么                                   |
| ------------------------------------------------------------ | -------------------------------------------- |
| Wind: TD-RiskA* 累积伤亡 0.00089 vs Distance 0.00226（↓61%） | 风险感知在高风险场景下显著降低伤亡           |
| Wind: TD-RiskA* 路径更长（577m vs 559m）                     | 算法愿意用距离换安全                         |
| Calm/Rain: 两者路径相同                                      | 算法不会在低风险场景下过度绕行（无过度保守） |



**需要补充的证据**：



- **Rain+Wind 联合场景**——当前只单独测了 Wind 和 Rain，需要证明三因子乘法耦合的非线性效应
- 路径叠加图上标注风场热点区域——展示"绕行"与"风险区"的空间对应关系



**一句话结论**：



> 实验2 证明了"复杂的风险建模不是过度工程化，而是能在关键时刻挽救 61% 的伤亡"。

## 实验3：噪声-安全帕累托权衡



**要证明的论点**：



> TD-RiskA* 的多目标框架能够在安全与噪声之间产生有意义的权衡，不同权重配置生成不同的帕累托最优路径。



**审稿人潜台词**：



*"你加了噪声维度，但噪声对路径的影响到底有多大？如果改权重路径都不变，说明噪声维度是可有可无的装饰。"*



**实验逻辑**：



text

```
自变量：w_n 从 0.05 扫描到 0.50（w_d 相应减小）
因变量：路径形状、存活概率、累积噪声、目标函数 J

如果 w_n 增大时 J 单调减小 → 归一化框架数学上正确
如果 w_n 增大时路径改变 → 噪声维度对路径有实质影响（关键！）
自变量：w_n 从 0.05 扫描到 0.50（w_d 相应减小）
因变量：路径形状、存活概率、累积噪声、目标函数 J

如果 w_n 增大时 J 单调减小 → 归一化框架数学上正确
如果 w_n 增大时路径改变 → 噪声维度对路径有实质影响（关键！）
```



**当前结果的问题**：



| 问题                    | 原因                                              | 解决方案                                     |
| ----------------------- | ------------------------------------------------- | -------------------------------------------- |
| 所有 w_n 下路径完全相同 | 当前场景中噪声贡献（~0.004）远小于距离贡献（~28） | 设计穿越住宅区 vs 绕行的强对比场景           |
| 无法展示 Pareto 前沿    | 单一 OD 对，无空间对比                            | 用住宅走廊场景制造"短但吵"vs"长但静"的二选一 |



**改进后的预期结果**：



text

```
场景设计：OD 对被住宅区夹住
- w_n < 0.3：路径穿越住宅区（短，噪声高）
- w_n = 0.3-0.5：路径切换点（Pareto 前沿）
- w_n > 0.5：路径绕行工业区（长，噪声低）

结果：路径长度与累积噪声呈负相关 → Pareto 前沿清晰可见
场景设计：OD 对被住宅区夹住
- w_n < 0.3：路径穿越住宅区（短，噪声高）
- w_n = 0.3-0.5：路径切换点（Pareto 前沿）
- w_n > 0.5：路径绕行工业区（长，噪声低）

结果：路径长度与累积噪声呈负相关 → Pareto 前沿清晰可见
```



**一句话结论**：



> 实验3 要证明的不是"噪声很重要"，而是"噪声重要到足以改变路径选择，且我们的框架能优雅地捕捉这种权衡"。

## 实验4：多标签剪枝效率



**要证明的论点**：



> Label-Setting 多标签机制在不损失最优性的前提下，有效控制搜索空间，保障计算可扩展性。



**审稿人潜台词**：



*"你搞了多标签、支配检查、标签上限，这些机制增加了算法复杂度。它们真的有用吗？会不会简单的单标签 A* 就够了？"*



**实验逻辑**：



text

```
自变量：max_labels = 1, 2, 4, 8, 16, 32, 50
因变量：路径质量（J）、运行时间、搜索节点数

如果 max_labels=1 和 max_labels=50 找到相同路径 → 该场景标签冲突少
如果 max_labels=4 在更大网格下优于 max_labels=1 → 多标签有实际价值
自变量：max_labels = 1, 2, 4, 8, 16, 32, 50
因变量：路径质量（J）、运行时间、搜索节点数

如果 max_labels=1 和 max_labels=50 找到相同路径 → 该场景标签冲突少
如果 max_labels=4 在更大网格下优于 max_labels=1 → 多标签有实际价值
```



**当前结果的问题**：



| 问题                          | 原因                               | 解决方案                        |
| ----------------------------- | ---------------------------------- | ------------------------------- |
| 所有策略找到相同路径          | 40×40 网格太小，路径上标签冲突极少 | 在 100×100 宏观网格复现         |
| 运行时间差异不大（6.5-8.0ms） | 搜索空间太小                       | 在 100×100 网格下差异会显著放大 |



**宏观网格下的预期结果**：



text

```
100×100 网格，OD = (10,10)→(90,90)，18:00 晚高峰：

max_labels=1  → 可能找到次优路径（被过早剪枝的标签可能是最优的）
max_labels=4  → 找到最优路径，运行时间适中
max_labels=50 → 找到最优路径，但运行时间显著更长

预期：max_labels=1 的 J 值可能比 max_labels=4 高 5-10%
     max_labels=4 的运行时间比 max_labels=50 快 2-3 倍
100×100 网格，OD = (10,10)→(90,90)，18:00 晚高峰：

max_labels=1  → 可能找到次优路径（被过早剪枝的标签可能是最优的）
max_labels=4  → 找到最优路径，运行时间适中
max_labels=50 → 找到最优路径，但运行时间显著更长

预期：max_labels=1 的 J 值可能比 max_labels=4 高 5-10%
     max_labels=4 的运行时间比 max_labels=50 快 2-3 倍
```



**一句话结论**：



> 实验4 要证明的不是"剪枝不损失最优性"（在小网格上这显而易见），而是"在城市级网格上，Label-Setting 是精度与效率的最佳平衡点"。

## 四组实验的论证逻辑总结



| 实验      | 论点                 | 审稿人质疑             | 核心证据                        |
| --------- | -------------------- | ---------------------- | ------------------------------- |
| **实验1** | 时间异质性影响路径   | "时间依赖是伪命题吗？" | 同一OD不同时间→不同路径         |
| **实验2** | 空间风险耦合影响路径 | "复杂建模有用吗？"     | 风场场景伤亡↓61%                |
| **实验3** | 多目标框架产生权衡   | "噪声维度是装饰吗？"   | 权重变化→路径切换→Pareto前沿    |
| **实验4** | 算法高效且最优       | "计算上撑得住吗？"     | Label-Setting 是精度/效率平衡点 |



**四句话串联**：



> 实验1证明**时间维度有实质影响**；实验2证明**空间维度有实质影响**；实验3证明**噪声维度有实质影响**；实验4证明**算法能在城市级规模上高效求解**。四个实验共同论证了论文的核心命题：*城市低空 UAV 路径规划必须考虑时空异质性，且 TD-RiskA* 能有效做到这一点。*

# 插图资源规范：assets/figures/

| 要求     | 说明                                                                 |
| -------- | -------------------------------------------------------------------- |
| 目录     | 矢量图放根目录即可（\graphicspath 已设），子图请用子文件夹分层管理   |
| 格式     | 优先 PDF（由 Python/Matplotlib 导出）或 SVG→PDF；位图最低 300 dpi    |
| 命名     | `小写-连字符-英文`，含义与所在章节对齐，如 `fig5-risk-field.pdf`     |
| 字体     | 出图时使用与正文一致的字号（9--10 pt），避免缩放后过小               |
| 配色     | 色盲友好、灰度可辨；同一组图保持配色一致                             |
| 版本     | 保留出图脚本（建议放 thesis/scripts/ 或对应章节脚本目录），便于复用  |

> 一句话原则：**图不要手改，靠脚本复现**。改一次数据，重跑一次脚本。

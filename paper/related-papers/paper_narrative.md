## 一、一句话故事

> 城市低空无人机的地面风险不是均匀的,也不是静态的--它随微气象、建筑峡谷和人口潮汐实时变化。本文用 Cox 比例风险模型建模"为什么风险会变",用 TD-RiskA\* 算法规划"在给定出发时刻下自动适配风险的最优路径"。

## 二、问题链(三层递进)

### 第一层:为什么要研究 TPR?

- 无人机在城市低空运行日益频繁(物流、巡检、应急)
- 坠机对地面行人/车辆/建筑构成**第三方风险**(TPR)
- 现有审批基于静态计划,实际执行面临动态环境
- **静态审批与动态环境之间的安全裂隙**需要弥合

### 第二层:现有 TPR 建模有什么问题?

| 问题               | 现有方法                 | 不足                                           |
| ------------------ | ------------------------ | ---------------------------------------------- |
| P_crash 是常数     | Pang (2022), Tang (2023) | 忽略了微气象对坠机概率的动态影响               |
| 人口密度是静态的   | 大多数方法               | 忽略了昼夜潮汐(商业区白天密集、住宅区夜间密集) |
| 噪声是简单距离衰减 | Pang (2022)              | 忽略了土地利用类型和时间段的敏感度差异         |
| 风险场不随时间变化 | Pang (2022), Tang (2023) | 同一位置白天和夜间的风险应该不同               |

### 第三层:我们怎么解决?

| 问题                   | 我们的方案                          | 技术手段              |
| ---------------------- | ----------------------------------- | --------------------- |
| P_crash 应该随环境变化 | Cox PHM:P_crash = f(风, 雨, 建筑)   | 比例风险模型          |
| 人口应该随时间变化     | POI 潮汐模型:ρ = f(时间, 土地利用)  | 引力模型 + 高斯核     |
| 噪声应该考虑时空敏感度 | S-T 矩阵:Cost = f(土地利用, 时间段) | GB 3096-2008 + WHO    |
| 路径应该随时间自适应   | TD-RiskA\*:时间维作为标签状态       | 在线查询 + 累积危险率 |

### 本文的新意(三个层次)

**新意 1:物理机制驱动的坠机概率建模**

> 现有方法将 P*crash 视为常数(Pang 2022)或随机扰动(Pang 2024)。本文引入 Cox 比例风险模型,将 P_crash 建模为风速、降雨、城市峡谷效应的乘积函数:
> $$P*{crash} = 1 - \exp(-\lambda*{base} \cdot f*{wind} \cdot f*{rain} \cdot f*{obs} \cdot \Delta t)$$
> 这使得坠机概率具有物理可解释性:风速超过抗风极限时 P_crash→1,建筑峡谷内 P_crash 放大。

**新意 2:时空异质的暴露密度建模**

> 现有方法使用静态人口密度。本文基于城市 POI 分布,构建引力模型 + 高斯核衰减 + 昼夜激活函数,生成时空动态的暴露密度:
> $$\rho(i, t) = \rho_{base}(i) \times \sum_k [W_k \cdot \tau_k(t) \cdot f_{decay}(d_{i,k})]$$
> 商业区白天人口密集(双峰高斯),住宅区夜间人口密集(反相位)。

**新意 3:时空敏感度的噪声成本建模**

> 现有方法将噪声视为简单距离衰减。本文构建 S-T 敏感度矩阵,使噪声成本同时受土地利用类型和时间段影响:
> $$Cost_{noise} = E_{noise}(z) \times \rho_{pop}(t) \times S_{landuse} \times T_{penalty}(t)$$
> 住宅区夜间惩罚是白天的 6.7 倍,工业区夜间惩罚只有白天的一半。

### §5 TD-RiskA\* 算法：时间依赖路径规划

#### 核心思想

传统 A* 在三维空间 (x,y,z) 上搜索，每个节点只记录位置。TD-RiskA* 的关键创新是：**把时间维从图拓扑中剥离，作为标签状态沿路径传播**。

```
传统 A*：
  节点 = (x, y, z)          ← 只有位置
  同一位置只保留一个最优标签

TD-RiskA*：
  标签 = (x, y, z, t, H, J) ← 位置 + 时间 + 累积危险率 + 累积代价
  搜索图始终是三维（26邻域），时间通过物理飞行耗时推算
```

#### 为什么这样做？

如果直接在四维时空网格上搜索，节点规模为 O(Nx × Ny × Nz × Nt)，计算量爆炸。TD-RiskA* 的做法是：**搜索图是三维的，时间是“附带”在标签上的状态量**，搜索复杂度与传统三维 A* 同阶，同时保持了完整的时间依赖风险感知能力。

#### 算法流程

```
输入：起点 (xs, ys, zs, t_depart)，终点 (xg, yg, zg)

1. 初始化标签 ℓ₀ = (xs, ys, zs, t_depart, H=0, J=0)
2. 将 ℓ₀ 压入开放列表 Q（按 f = J + h 排序）

3. while Q 非空：
   a. 弹出 f 值最小的标签 ℓ_cur
   b. 如果 ℓ_cur 到达终点 → 返回路径
   c. 对 ℓ_cur 的 26 个空间邻居：
      i.  计算物理距离 d 和飞行耗时 Δt = d / v
      ii. 推算到达时刻 t_next = t_cur + Δt
      iii.在线查询风险值：
          P_crash, E_fatality, E_property, R_noise ← Tensor(x, y, z, t_next)
      iv. 计算单步风险增量（累积危险率、致死、财产、噪声）
      v.  计算归一化代价 ΔJ
      vi. 构造新标签 ℓ_next = (x, y, z, t_next, H_new, J_new)
      vii.支配检查：ℓ_next 是否被已有标签支配？
      viii.将 ℓ_next 压入 Q

4. Q 空 → 搜索失败
```

#### 关键机制

**1. 在线查询（Online Querying）**

风险张量在规划前基于天气预报和人口统计数据预计算，形成 4D 张量 Cost(x,y,z,t)。搜索过程中，每次节点扩展时，根据路径累计飞行时间 t_next 查询对应时刻的风险值。这使得算法能感知“当前时刻的风险”，而不需要在四维空间上展开搜索。

```
示例：
  起点出发时刻 t=18:00
  飞行 500m 后到达位置 P，累计时间 t=18:05
  → 查询 Tensor(P, 18:05) 得到该时刻的风险值

  如果出发时刻改为 t=06:00
  → 查询 Tensor(P, 06:05) → 不同的风险值
  → 可能产生不同的路径选择
```

**2. 累积危险率 H（Cumulative Hazard Rate）**

传统做法用存活概率连乘：P_surv = Π(1 - p_crash_i)
问题：长距离路径连乘会导致数值下溢。

TD-RiskA\* 用累积危险率 H = -ln(P_surv)，将连乘转化为加法：

```
H_new = H_cur + h_step
其中 h_step = -ln(1 - p_crash)
P_surv = exp(-H)
```

H 是加法量，不会下溢，且存活概率约束 H ≤ -ln(P_th) 等价于 P_surv ≥ P_th。

**3. 归一化与多目标代价**

各风险分量量纲不同（致死人数、元、噪声单位、米），通过张量极值归一化统一到 [0,1]：

```
ΔJ = w_f × (ΔC_fatality / Ω_f) + w_p × (ΔC_property / Ω_p)
   + w_n × (ΔC_noise / Ω_n) + w_d × (d / d_max)
```

权重 w_k 表达决策偏好（安全优先 / 静音优先 / 效率优先）。

**4. 时间自适应性（核心特性）**

同一 OD 对在不同出发时刻，算法查询到的风险值不同 → 产生不同路径：

```
t=08:00 出发：风速低 → 直穿中心（777.8m）
t=18:00 出发：风+雨叠加 → 绕行中心（813.0m）
t=22:00 出发：风暴已过 → 直穿中心（777.8m）
```

这不是算法在“搜索最佳出发时间”，而是算法对给定出发时刻的风险环境自动适配。

#### 与传统 A\* 的对比

| 特性       | 传统 A\*       | TD-RiskA\*                      |
| ---------- | -------------- | ------------------------------- |
| 搜索维度   | 3D (x,y,z)     | 3D (x,y,z)，时间作为标签状态    |
| 风险感知   | 静态风险场     | 时间依赖风险场（在线查询）      |
| 数值稳定性 | 无特殊处理     | 累积危险率 H = -ln(P_surv)      |
| 多目标     | 单目标（距离） | 四维代价（致死+财产+噪声+距离） |
| 代价归一化 | 不需要         | 张量极值归一化到 [0,1]          |
| 时间自适应 | ❌             | ✅ 不同出发时刻 → 不同路径      |

## 五、审稿人可能的问题与回应

### Q1: "你的方法和 Pang (2022) 有什么区别?"

> "Pang (2022) 建立了 TPR 的静态框架,P_crash 是常数。本文将 P_crash 从常数扩展为 Cox PHM 的环境函数,使其随风速、降雨、建筑密度动态变化。此外,我们的噪声模型引入了 S-T 敏感度矩阵,比 Pang 的距离衰减更精细。"

### Q2: "你的'时间依赖'和 TRC (2026) 的 4D 时空有什么区别?"

> "TRC (2026) 的风险来源是交通监控数据(数据驱动),缺乏物理机制支撑。我们的风险来源是 Cox PHM(微气象耦合)和潮汐模型(人口节律),是物理可解释的。此外,我们同时建模了致死、财产、噪声三个维度,TRC 只考虑碰撞风险。"

### Q3: "你的环境是预计算的,算'在线查询'吗?"

> "我们的环境张量在规划前基于天气预报和人口统计数据预计算。'时间依赖'的含义是:同一空间位置在不同时刻具有不同的风险值,算法根据路径累计飞行时间查询对应时刻的风险值。这与真正的'在线感知'不同,但符合城市低空航路预先报批的实际场景。"

### Q4: "噪声对路径的影响有多大?"

> "实验表明,当噪声权重 w_n 超过 0.50 时,算法选择绕行住宅区,噪声降低 63%,致死风险同时降低 66%。在随机 100 个 OD 对中,47.5% 的路径随权重调整而变化,证明 Pareto 效应是鲁棒的。"
